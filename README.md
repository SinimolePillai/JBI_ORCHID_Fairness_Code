This repository contains the R code used for the manuscript:

"Pipeline-Aware Fairness Auditing in Organ Donation Decision Systems"

## Data

The ORCHID dataset is available from PhysioNet and is subject to its access requirements.

## Software

R version 4.5.1

Packages:
- caret
- pROC
- PRROC
- dplyr
- ggplot2
- xgboost
# Repository Structure

01_logistic_regression.R
    Logistic regression pipeline and fairness evaluation

02_xgboost_analysis.R
    XGBoost pipeline and fairness evaluation

## Data Availability

The ORCHID dataset is publicly available through PhysioNet and is subject to its data access requirements.

## Reproducibility

Users should obtain ORCHID data independently and update file paths before executing the scripts.
